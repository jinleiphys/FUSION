# Final State Interactions in Near Threshold Meson Production from pp Collisions

> We analyse the experimental data on near threshold $π$, $η$, $ω$, $η'$ and $K^+$ production from $pp$ collisions and show that all information gained so far is compatible with approximately constant production matrix elements when including the rescattering between the baryons in the final states. Different methods to include the final state interactions are discussed and their range of validity is indicated. We, furthermore, show that Dalitz plots for the proton-meson invariant mass spectra at different energies should be suited to distinguish between final state interactions and resonant production amplitudes.

## Key claim

All available near-threshold data on π, η, ω, η' and K⁺ production from pp collisions are compatible with approximately constant production matrix elements, provided that final-state interactions (FSI) between the baryons are included via the inverse Jost-function method; the analysis is limited to excess energies ε ≤ 40 MeV where the effective range approximation holds, though the method appears to work up to about 100 MeV for η and η' production.

## Method

The authors extract an average production amplitude |M| from total cross section data by dividing out the three-body phase space and the FSI correction factor, using the inverse Jost function with effective range parameters (scattering length a_s = -7.8 fm, effective range r_s = 2.79 fm) to account for S-wave nucleon-nucleon rescattering. They apply this procedure to data on pp→ppπ⁰, pp→pnπ⁺, pp→ppη, pp→ppω, pp→ppη', pp→pΛK⁺, and pn→pnη reactions, fitting a constant |M| to the energy-dependent amplitude. For the ω meson, they also incorporate a Breit-Wigner spectral function with width Γ = 8.41 MeV to account for the finite meson width near threshold.

## Key numbers

- pp→ppπ⁰ production amplitude |M| ≈ 82 fm (with Coulomb correction) or 79 fm (without), extracted from IUCF and CELSIUS data
- pp→ppη production amplitude |M| ≈ 61 fm, extracted from SATURNE-II, PINOT, and CELSIUS data
- pp→ppω production amplitude |M| ≈ 33 fm (with finite ω spectral function), from SPES-III data
- pp→ppη' production amplitude |M| ≈ 19.0 fm, from SPES-III and COSY-11 data
- pp→pnπ⁺ production amplitude |M| ≈ 234 fm, from IUCF data
- pn→pnη production amplitude |M| ≈ 157 fm, from CELSIUS data
- pp→pΛK⁺ production amplitude |M| ≈ 43 fm, from COSY-11 and COSY-TOF data
- Effective range parameters for pp S-wave: a_s = -7.8 fm, r_s = 2.79 fm (from Stoks)
- ω-meson vacuum width Γ = 8.41 MeV used in spectral function

## Context

This work extends the Watson-Migdal approach (Watson 1952, Migdal 1955) for final-state interactions to a systematic analysis of multiple meson production channels, building on the authors' earlier proposal (Sibirtsev 1997) to analyze data via average reaction amplitudes. The method enables extraction of constant production matrix elements that can be used to predict cross sections for channels with different baryon final states, and conversely allows "measurement" of baryon-baryon FSI that are not accessible in scattering experiments. The analysis contradicts the need for resonant production amplitudes at low excess energies, but shows that at ε ≥ 150 MeV for η production, the S₁₁(1535) resonance structure becomes distinguishable from FSI effects in Dalitz plots.
